# NGS-Klf4-analysis-public
Scripts used for Next Generation Sequencing data analysis for mESC Klf4 project

This repository contains scripts for processing RCMC/TT-seq/ATAC-seq/CUT&RUN data, including:

1. Converting HiC-Pro allValidPairs files to pairtools pairs format
2. Selecting Klf4 capture-region contacts
3. Generating cooler/mcool files

Genome: mm10  
Capture region: chr4:55,200,000-55,700,000  
Resolution: 5 kb
